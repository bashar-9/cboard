# CBoard Skills

This folder is intentionally limited to skills useful for CBoard:

- Next.js, React, TypeScript, Zustand, Tailwind, and Radix UI
- UI/UX, accessibility, visual checks, and web performance
- Security review and dependency scanning
- Testing, browser automation, debugging, linting, and code review
- Git, Vercel, documentation, and brainstorming

Unrelated stacks and services were removed to keep the project focused.
